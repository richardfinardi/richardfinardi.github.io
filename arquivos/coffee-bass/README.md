# Coffee & Bass — arquivos para bordado

Arquivos vetoriais 2D, sem efeito 3D, preparados para envio à empresa de bordado.

- `coffee_bass_bordado_vetorizado.svg` — vetor principal, ideal para uso sobre o tecido.
- `coffee_bass_bordado_vetorizado_fundo_preto.svg` — versão de visualização com fundo preto.
- `coffee_bass_bordado_vetorizado.eps` — versão EPS.
- `coffee_bass_bordado_vetores.zip` — pacote com os três arquivos vetoriais acima.

Para bordar em máquina, a empresa de bordado normalmente converte o vetor para o formato da máquina, como DST, PES ou JEF, definindo densidade e sequência dos pontos conforme o tamanho final.
