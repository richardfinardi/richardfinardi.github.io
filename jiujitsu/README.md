# Jiu-Jitsu App

PWA para registrar e acompanhar treinos de Jiu-Jitsu.

## Estrutura
- Front-end: GitHub Pages em /jiujitsu/
- Banco: Google Sheets `JIU JITSU APP - BANCO DE DADOS`
- Backend: Google Apps Script Web App em `jiujitsu/apps-script`

## Para conectar
1. Criar/abrir um projeto Apps Script na mesma conta Google.
2. Colar `Code.gs` e `appsscript.json`.
3. Implantar como Web App.
4. Copiar a URL `/exec` para `config.js > API_URL`.
